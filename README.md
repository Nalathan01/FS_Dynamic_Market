# FS25 DynamicMarket

A mod for Farming Simulator 25 that introduces realistic market dynamics and price fluctuations.

## 🚀 Download

Always get the latest version directly here:

👉 [Forbidden Mods (always up to date)](https://forbidden-mods.de/filebase/file/78050-dynamic-market/)

👉 [Official GIANTS ModHub](https://www.farming-simulator.com/mod.php?mod_id=366174&title=fs2025)

## 🔧 Installation

1. Click the download link above.
2. Download the `.zip` file.
3. Move the file into your FS25 mod folder (usually located at `Documents/My Games/FarmingSimulator2025/mods`).
4. Activate the mod in your savegame directory when starting the game.


# FS25 DynamicMarket

Ein Mod für den Landwirtschafts-Simulator 25, der die Marktdynamik und Preisgestaltung realistischer gestaltet.

## 🚀 Download

Lade dir immer die aktuellste Version direkt hier herunter:

👉 [Forbidden Mods (immer aktuell)](https://forbidden-mods.de/filebase/file/78050-dynamic-market/)

👉 [Offizieller GIANTS ModHub](https://www.farming-simulator.com/mod.php?mod_id=366174&title=fs2025)

## 🔧 Installation

1. Klicke auf den Download-Link oben.
2. Lade die `.zip`-Datei herunter.
3. Verschiebe die Datei in deinen LS25 Mod-Ordner (normalerweise unter `Dokumente/My Games/FarmingSimulator2025/mods`).
4. Aktiviere den Mod beim Spielstart.
